### 集成开发环境（IDE）

### 编译器、构建工具、包管理

C 语言主流编译器包括：GCC、Clang/LLVM、MSVC.

其中 Linux 通常使用 GCC、MacOS 通常使用 Clang/LLVM、Windows 通常使用 MSVC 或 MinGW，后者是 Windows 下的轻量级 GCC 工具链。

C 语言标准包括 K&R C (未标准化)、ANSI C (C89)、C99、C11、C17 (C18)、C23.

C 构建工具包括：CMake、Ninja、MSBuild.

C 包管理：五花八门，最多是不使用包管理。

#### Make

GNU Make 是中小型项目常用的构建工具。其构建描述使用 `Makefile` 文件。

书写规则：

```Makefile
target ...: prerequisities ...
    recipe
    ...
```

其中 `target` 可以是目标文件、可执行文件或伪标签，`prerequisities` 为生成该 `target` 所依赖的文件，`recipe` 为该 `target` 要执行的命令。

在默认的方式下，也就是我们只输入 `make` 命令。那么，

1. `make` 会在当前目录下找名字叫 `Makefile` 或 `makefile` 的文件。

2. 如果找到，它会找文件中的第一个 `target`.

3. 如果 `target` 文件不存在，或是 `target` 所依赖的后面的文件的文件修改时间要比 `target` 这个文件新，那么，他就会执行后面所定义的命令来生成 `target`.

4. 如果 `target` 所依赖的文件也不存在，那么 `make` 会在当前文件中找目标为该文件的依赖性，如果找到则再根据那一个规则生成依赖的文件文件。直到依赖补全。

文件可能很长，或者依赖比较多，这容易导致出错，可以通过定义变量的方式简写，使用 `$(...)` 来解除变量。

```Makefile
variable = expression

target: $(variable)
    recipe
```

注释使用 `# ...`，在 `Makefile` 中的 `recipe` 必须使用 Tab 键开始。

参见：[跟我一起写 Makefile](https://seisman.github.io/how-to-write-makefile/)。
